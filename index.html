Mobile Controls

Basic Controls

  • Tap: Reveal a cell
  • Long press: Flag a cell
  • Flag Mode: Toggle to flag/unflag cells

Chording

Tap a revealed number with the same number of flags around it to reveal all adjacent cells.

Keyboard Controls

  • Arrow Keys: Navigate between cells
  • Space/Enter: Reveal a cell
  • F: Flag/unflag a cell
